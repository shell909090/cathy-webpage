## 模块 1：不是所有人都适合同一套英语课

### 标题

英语课程要根据年龄、基础和目标来匹配

### 正文

儿童和成人学英语，目标完全不同。  
零基础、启蒙、阅读理解、雅思口语、商务英语、旅游英语，也不应该用同一套方式教学。

SpeakUp 会先了解学习者的年龄、基础和目标，再匹配外教和课程计划。

---

## 模块 2：儿童与青少年课程方向

### 英语启蒙

适合刚开始接触英语的孩子，重点是建立兴趣、听音反应和基础表达。

### 自然拼读

适合需要建立字母、发音和拼读规则的孩子，帮助孩子从"认单词"逐步过渡到"能读、能拼、能说"。

### 绘本伴读

适合喜欢故事和图画内容的孩子。外教可以带孩子听读绘本，并围绕故事内容进行简单问答和表达。

### 阅读理解

适合需要提升英文阅读能力的孩子。课堂可以围绕文章主题、关键词、句意理解和复述表达进行训练。

### 日常口语

适合想提升基础表达能力的儿童和青少年，围绕家庭、学校、兴趣、生活场景等主题练习。

### KET/PET 口语基础

适合准备 KET/PET 或希望提前打好口语基础的学生。重点不是只背模板，而是提升听懂问题、组织回答和自然表达的能力。

## 模块 3：成人课程方向

### 零基础英语

适合想重新开始学英语的成人，从基础发音、简单词句和常见场景开始。

### 日常口语

适合希望提升日常交流能力的学习者，比如自我介绍、购物、问路、点餐、社交沟通等。

### 旅游英语

适合准备出国旅行的人群，围绕机场、酒店、餐厅、交通、购物、突发情况等场景训练。

### 商务英语

适合有职场沟通需求的人群，围绕会议、邮件、汇报、客户沟通、面试和商务社交等场景练习。

### 雅思口语

适合正在备考雅思的学习者，重点练习 Part 1、Part 2、Part 3 的表达思路、回答结构和流利度。

### 听力与口语强化

适合"听不懂、说不出"的成人学习者，通过一对一高频互动提升英语反应速度。

## 模块 4：如何判断自己适合哪类课

| 学习者情况 | 推荐方向 |
|---|---|
| 孩子刚接触英语 | 英语启蒙 / 自然拼读 / 绘本伴读 |
| 孩子发音和拼读弱 | 自然拼读 |
| 孩子喜欢绘本 | 绘本伴读 |
| 孩子阅读理解弱 | 阅读理解 |
| 孩子会学但不会说 | 儿童日常口语 / 一对一口语训练 |
| 准备 KET/PET | KET/PET 口语基础 |
| 成人零基础 | 零基础英语 |
| 想练日常交流 | 日常口语 |
| 准备出国旅行 | 旅游英语 |
| 工作需要英语 | 商务英语 |
| 备考雅思 | 雅思口语 |
| 想提升实际交流 | 日常口语 / 听力与口语强化 |

## 模块 5：课程如何匹配外教

### 标题

不同课程方向，需要匹配不同类型的外教

### 正文

儿童启蒙和自然拼读，更需要擅长低龄互动、引导开口和建立兴趣的老师。  
成人口语和商务英语，更需要能围绕真实场景进行对话训练的老师。  
雅思口语，则需要老师帮助学生建立回答结构、话题展开和流利表达。

SpeakUp 会根据学习者的年龄、基础、目标和课堂反馈，匹配更适合的外教。
